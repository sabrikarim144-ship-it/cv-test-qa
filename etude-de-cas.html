00 — Architecture & Méthodologie

Deux écosystèmes, une exigence commune

Confidentialité préservée · Périmètres anonymisés
Système A En production · Autonomie complète

Portail Web & CRM Institutionnel

Audit d'un écosystème déjà exposé au public : vérification de la cohérence documentaire, contrôle de l'infrastructure, recette fonctionnelle multi-terminaux et sécurité OWASP.

Python 3.11 / Django MVT uWSGI / HTTP/2.0 LCP 0,21s · CLS 0 · 5 ms
  • 01 Audit statique : confrontation manuel de maintenance vs configuration réelle (secrets, PYTHONPATH, WSGI).
  • 02 Boîte grise : corrélation entre erreurs UI et journaux HTTP/2.0 pour isoler la cause applicative.
  • 03 Sécurité & UX : Contenu Mixte HTTPS, validation anti-XSS, absence de Honeypot, responsive & I18n.
Système B Pré-production · Recette pré-MEP

Plateforme Transactionnelle SaaS

Validation amont d'une application métier gérant réservations, sessions, jauges de capacité, rôles utilisateurs et parcours de paiement avant ouverture au public.

Spring Boot 3 / Java 17 Spring Security 6 · JWT · RBAC Angular 17 / TypeScript
  • 01 Recette API REST : 17 scénarios Postman validant règles métier (BLL), limites de capacité, RBAC et IDOR.
  • 02 Audit SPA & IAM : détection d'une désynchronisation Front-to-Back (404) et de 6 routes Angular manquantes.
  • 03 Automatisation E2E : transcription des anomalies en scripts Playwright/TypeScript et proposition CI/CD.
Bloc 1 · Analyse & Shift-Left

Concevoir avant d'exécuter

Revue documentaire statique, cartographie des risques métier, stabilisation de l'environnement de recette et conception de cas nominaux, limites et sécurité.

Bloc 2 · Boîte Noire & Grise

Isoler la cause racine

Croisement systématique entre le comportement observé côté navigateur, les réponses HTTP Postman et les journaux serveur pour fournir des tickets directement exploitables.

Bloc 3 · E2E & CI/CD

Verrouiller dans le temps

Conversion des défauts majeurs en tests Playwright reproductibles avec baseline d'échec prouvée, rapport HTML automatique et workflow GitHub Actions.
